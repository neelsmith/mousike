# mousike

Parse ancient Greek musical notation in Sowerby notation, align with textual editions, translate to MIDI representation.


- [documentation](https://neelsmith.github.io/mousike/) (in progress)


> **Acknowledgments**: The definition of the encoding system used in this package in `src/mousike/data/sowerby_system.cex` is directly taken from work developed by Zach Sowerby in his 2019 Holy Cross undergraduate thesis work.
