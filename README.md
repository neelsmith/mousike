# mousike

A Python package and data resources for working with texts including ancient Greek musical notation. Musical notation is encoded in Zach Sowerby's URN scheme. The Python package can parse the notation, align notation with textual editions, and translate musical texts to MIDI representations.

The Python package is available from Pypi. Data releases are in the `releases` directory.


- [documentation](https://neelsmith.github.io/mousike/) (in progress)
- [release notes](./releases.md) for Python package
- [release notes](./datareleases.md) for data sets


> **Acknowledgments**: The definition of the encoding system used in this package in `src/mousike/data/sowerby_system.cex` is directly taken from work developed by Zach Sowerby in his 2019 Holy Cross undergraduate thesis work.
